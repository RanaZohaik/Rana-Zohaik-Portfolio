# Rana Zohaik — Editorial Developer Portfolio

A modern, high-fashion editorial portfolio designed for **Rana Zohaik** — Mobile & Full-Stack Architect.

## ✨ Features

- **Cinematic 3D Hero Layering**: Seamless depth composition featuring solid bone-cream typography behind the subject portrait, intersected with sharp stroke outlines layered in front.
- **Dynamic Hero Switcher**: 1-click toggle between `RANA ZOHAIK` and `PORTFOLIO` display modes.
- **Continuous Ticker Ribbon**: Smooth running marquee highlighting core technology competencies.
- **Domain Capability Quadrants**: Architectural pillars covering Mobile Engineering, Backends & Resilient APIs, Desktop POS, and Real-Time Telemetry.
- **Editorial About Spread**: Magazine-style layout highlighting craft, philosophy, and production performance metrics.
- **Technical Arsenal**: Categorized breakdown across Mobile, Backend, Databases/Cloud, and Web/Desktop ecosystems.
- **Featured Works & Case Studies**: Project showcases for *Fixio*, *AR Shanwari Hujra*, and *STB Driver* with an interactive case study modal.
- **Interactive Contact Hub**: One-click copy email button with feedback tooltip, and direct channels to GitHub, LinkedIn, and Instagram.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Motion & Interactions**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Bebas Neue, Anton, Plus Jakarta Sans, Space Grotesk
- **Styling**: Pure Modern CSS with responsive design

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
